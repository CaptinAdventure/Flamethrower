Repository read/search permissions

When enabled, approve only ACP read and search requests that report at least one existing location, with every location resolving inside the configured project directory or matching an additional allowed path below, and offer an “allow once” choice. Relative locations are resolved against the ACP project directory; relative paths containing .. are not automatically approved. Other requests still require manual approval.

This is an approval convenience, not repository isolation or a sandbox. ACP servers are trusted; reported locations and kinds are agent-supplied metadata, and reads may expose secrets.
